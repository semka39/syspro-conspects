# Сиспро конспекты

## Структура папок

* **`dmta/`** — оригинальное пособие от Когабаева.
* **`vishal/`** — оригинальное пособие от Бардакова.
* **`angem/`** — конспекты, сформированные на основе фотографий с доски (с самой первой лекции).
* **`matan/`** — конспекты, также составленные по фотографиям с доски. *материалы примерно первых двух лекций утеряны.*

## Рекомендации по просмотру

Для просмотра и редактирования оригинальных Markdown (`.md`) файлов лучше всего использовать **Obsidian**, так как он наиболее корректно отображает всю разметку и математические формулы.

## Как контрибьютить

Если вы хотите внести изменения или дополнить материалы, буду рад вашим пулл-реквестам! 

**Важно:** после внесения изменений в `.md` файлы и **перед коммитом** необходимо обновить PDF-версии конспектов. Для этого в корне репозитория предусмотрен скрипт `md2pdf.py`.

### Шаги для сборки PDF

1. Перед первым использованием установите необходимые зависимости из файла `requirements.txt`:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите скрипт в корневой папке для генерации PDF:
   ```bash
   python md2pdf.py
   ```

3. **Офлайн-режим:** Скрипт поддерживает генерацию без доступа к интернету с помощью флага `--offline`. Для его использования необходимо предварительно установить локально `katex`:
   ```bash
   npm install katex
   python md2pdf.py --offline
   ```

Только после того, как PDF-файлы будут сгенерированы, индексируйте изменения и делайте коммит.
